# Lunvik

A landing page for a heat pump installer, in English and Norwegian, with a savings
calculator, fixed prices and a booking form.

Live: https://wiggendigital.github.io/lunvik/ (English) and
https://wiggendigital.github.io/lunvik/no.html (Norwegian).

Lunvik is a fictional company. The page is a sample project, designed and built by
Wiggen Digital. The booking form sends nothing.

This repository holds the built page: two HTML files made from one template, one
stylesheet and one script. There is no framework and nothing to install.

Measured with Lighthouse on a phone profile: performance 99, accessibility 100,
best practices 100, SEO 100.
